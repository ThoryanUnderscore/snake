# snake
Jeu snake recréé avec pdcurses et le langage C

Principes du jeu :

- Remplir l'écran avec le serpent
- Ne pas se cogner contre les murs
- Ne pas se cogner contre soi-même

Gestion de la vitesse (changer le DELAY du define)
Gestion de la taille de l'écran (changer le WIDTH et HEIGHT du define)

Score affichable à la fin de la partie, ou lorsque l'on quitte l'interface de jeu, dans la console.
